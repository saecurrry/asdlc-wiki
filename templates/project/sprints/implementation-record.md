# Sprint implementation record

## Approved scope and input versions

Record sprint/story IDs, accepted BRD/HLD/ADR/contract/guidance versions and authorised workspace boundaries. Missing sources are blockers, not inferred consent.

| Story | Input IDs / versions / hashes | Worker / run | Base commit | Result commit / dirty digest | Changed files | Scope justification |
|---|---|---|---|---|---|---|

## Implementation and verification

| Check / case | Requirement / acceptance criterion | Code version | Actual command | Executed / planned / skipped / unavailable | Result | Output / evidence hash |
|---|---|---|---|---|---|---|

Separate implemented, independently reviewed, verified and accepted statuses. Record co-developed tests and integration prerequisites; no check is passed without executed evidence.

| Record ID | Location / impact | Owning stage | Required action / owner | Status | Review / evidence |
|---|---|---|---|---|---|

Business gaps return to requirements; material technical decisions return to architecture. Independent review evaluates actual code against approved story scope. Next handoff is integrated sprint validation, not automatic human acceptance.
