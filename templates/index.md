## Instantiate a project

Copy the entire project/ folder to projects/<project-id>/. Replace PROJECT_ID, PROJECT_NAME and other placeholders. Set created_at/updated_at to actual timestamps. Do not fabricate approvals or completed work. The project index links to shared folders correctly when copied to projects/<project-id>/.

State format is a starter contract to align with the ASDLC tool during implementation. The template is inert: project_id is unset and record arrays are empty. Validate and initialise through the tool before treating it as executable state.
